# M24 Final Exam Practice

253 questions (120 module + 133 textbook) covering site preparation and turf establishment: clearing, fumigation, tillage and the squeeze test, plowing/disking/harrowing/rototilling, soil amendments (sand, perlite, vermiculite, sawdust, muck, peat), basic and starter fertilizer, drain tile depth and spacing, catch basins, irrigation timing, rough and fine grading; blends vs. mixtures, vegetative planting materials, purity, viability, and pure live seed with cost problems; seeding timing, rates, and methods (drop seeders, rolling, cultipackers, hydroseeding); sodding, sod washing, plugging, stolonizing, and sprigging; mulching functions; and postplanting mowing, irrigation, fertilization, topdressing, and pest management. The Textbook sub-test covers Ch. 8, pp. 303-334: Propagation. The Overview page (scenario, objectives, readings) is not quizzed. Answer options are length-balanced so the longest choice is not a giveaway. 10 at a time.
