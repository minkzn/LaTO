# TURF 235 Exam 2 Study Site

## Contents
- `study-guide.html` — searchable/printable study guide
- `quiz.html` — 100-question exams drawn from the 250-question pool, 10 at a time
- `questions.json` — the 250-question pool (full per-module banks live in `../M#/questions.json`)
- `styles.css`

## Question distribution
Built on the Exam 1 pattern (exact quiz repeats are rare; the professor keeps quiz relationships but flips one variable or rewords the definition). About half the questions take M10–M20 quiz facts from the opposite direction (inverses, complements, which-is-NOT, term and definition swapped); the other half are module-page details from the per-module banks. Questions are interleaved across modules. Where a quiz answer key disagrees with the module pages, the quiz key is followed.

## Accuracy / source rules
- Each question is modeled on the real Canvas quiz style for its module and sourced from that module's own course PDFs, with a curated slice of textbook enrichment on the same topics where it adds real depth.
- Every question reveals its source after submission.

## Quiz behavior
- 10 questions per batch
- correct answers retire
- missed answers cycle to the back
- progress saved per module filter in localStorage
