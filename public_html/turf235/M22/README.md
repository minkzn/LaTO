# M22 Final Exam Practice

176 questions (97 module + 79 textbook) covering cultivation: definition and principal types, the Mascaro verticutter and aerifier, hollow-tine (core) cultivation, the aerification misnomer, core removal vs. reincorporation, percent soil displacement with worked tine-size/spacing problems, sand-topdressing layering, drill-and-fill, thatchlike derivative, matting, deep cultivation, HTC advantages and disadvantages, solid-tine cultivation, slicing, spiking, water-injection and sand-injection cultivation, vertical mowing depths, vertical mower-seeders, Graden blade, WaterWick, and the XGD System. The Textbook sub-test covers Ch. 6, pp. 191-201, 207-212: Cultivation, Wetting Agents, Colorants, PGRs, and Biostimulants. The Overview page (scenario, objectives, readings) is not quizzed. Answer options are length-balanced so the longest choice is not a giveaway. 10 at a time.
